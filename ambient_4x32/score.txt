# ------------------------------------------------------------
# 来源：scores/ambient_4x32.json（同一份数据的**文本视图**）
# 用法：py tools/score_push.py --file scores/ambient_4x32.txt --step-ms 250 --loop 1
#        py tools/score_to_bin.py --file scores/ambient_4x32.txt --loop 1
# ------------------------------------------------------------
# ★ 这是 **4 轨合并谱**：同一时刻所有轨的键位 OR 进一个 bitmap
#   （与 scores/demo_camfg_4x32.txt 同款）。
# ★ 每步的 dur = 该步所有轨里**最长**的那条门（便于 .txt 单独下发时不丢延音）。
# ★ 步长 250 ms；共 32 步 = 8.00 s / 轮。
#
# ── 轨与音色（板级音色库 patch_bank.v 的 8 套）────────────────
#  轨0 弦乐群    音色 弦乐群        patch=6 algo=6 FB=5  声部 124 part 0  主铺底（每 8 步换一个和弦音）
#  轨1 羽管键琴   音色 羽管键琴       patch=0 algo=0 FB=0  声部 125 part 1  稀疏高音点缀（错位落在和弦尾部）
#  轨2 管风琴    音色 管风琴        patch=4 algo=4 FB=0  声部 126 part 2  低音 drone（EGT=1 ⇒ 永续不衰减）
#  轨3 钟      音色 钟          patch=7 algo=7 FB=0  声部 127 part 3  远景一记（环形 FM，衰减快）
#
# ── 键号表（半音偏移，0=C3）────────────────────────────────
# 0=C3 1=C#3 2=D3 3=D#3 4=E3 5=F3 6=F#3 7=G3 8=G#3 9=A3 10=A#3 11=B3
# 12=C4 13=C#4 14=D4 15=D#4 16=E4 17=F4 18=F#4 19=G4 20=G#4 21=A4
# 22=A#4 23=B4（**上限**：线上 bitmap 只有 24 bit ⇒ 键号 ≤ 23）
#
