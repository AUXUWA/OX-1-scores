# 来源：scores/blues_shuffle_4x32/score.json（同一份数据的**文本视图**）
# 用法：py tools/score_push.py --file scores/blues_shuffle_4x32/score.txt --step-ms 150 --loop 1
#        py tools/score_to_bin.py --file scores/blues_shuffle_4x32/score.txt --step-ms 150 --loop 1
# ------------------------------------------------------------
# ★ 4 轨合并谱：同一时刻所有轨的键位 OR 进一个 bitmap
#   （与 scores/demo_camfg_4x32/score.txt 同款）。
# ★ 每步的 dur = 该步所有轨里**最长**的那条门（便于 .txt 单独下发时不丢延音）。
# ★ 步长 150 ms；共 32 步 = 4.80 s / 轮。
#
# ── 轨与音色（板级音色库 patch_bank.v 的 8 套）────────────────
#  轨0 拨弦     音色 拨弦         patch=2  声部 124 part 0  吉他 riff（切分）
#  轨1 电钢琴    音色 电钢琴        patch=1  声部 125 part 1  七和弦 comping（2、4 拍）
#  轨2 管风琴    音色 管风琴        patch=4  声部 126 part 2  低音（根音-五音-七音走动）
#  轨3 金属打击   音色 金属打击·树形    patch=3  声部 127 part 3  底鼓 + 扫军鼓 + hi-hat
#
# ── 键号表（半音偏移，0=C3）────────────────────────────────
# 0=C3 1=C#3 2=D3 3=D#3 4=E3 5=F3 6=F#3 7=G3 8=G#3 9=A3 10=A#3 11=B3
# 12=C4 13=C#4 14=D4 15=D#4 16=E4 17=F4 18=F#4 19=G4 20=G#4 21=A4
# 22=A#4 23=B4（**上限**：线上 bitmap 只有 24 bit ⇒ 键号 ≤ 23）
