# 来源：scores/orchestral_4x32.json（同一份数据的**文本视图**）
# 用法：py tools/score_push.py --file scores/orchestral_4x32.txt --step-ms 150 --loop 1
#        py tools/score_to_bin.py --file scores/orchestral_4x32.txt --loop 1
# ------------------------------------------------------------
# ★ 这是 **4 轨合并谱**：同一时刻所有轨的键位 OR 进一个 bitmap
#   （与 scores/demo_camfg_4x32.txt 同款）。
# ★ 每步的 dur = 该步所有轨里**最长**的那条门（便于 .txt 单独下发时不丢延音）。
# ★ 步长 150 ms；共 32 步 = 4.80 s / 轮。
#
# ── 轨与音色（板级音色库 patch_bank.v 的 8 套）────────────────
#  轨0 弦乐群    音色 弦乐群        patch=6 algo=6 FB=5  声部 124 part 0  主旋律（4 步一个乐句，legato）
#  轨1 拨弦     音色 拨弦         patch=2 algo=2 FB=0  声部 125 part 1  八分音符琶音拨奏（根-五-三-五）
#  轨2 管风琴    音色 管风琴        patch=4 algo=4 FB=0  声部 126 part 2  管乐低音（每和弦一个长音）
#  轨3 金属打击   音色 金属打击·树形    patch=3 algo=3 FB=0  声部 127 part 3  定音鼓（强拍 + 次强拍）
#
# ── 键号表（半音偏移，0=C3）────────────────────────────────
# 0=C3 1=C#3 2=D3 3=D#3 4=E3 5=F3 6=F#3 7=G3 8=G#3 9=A3 10=A#3 11=B3
# 12=C4 13=C#4 14=D4 15=D#4 16=E4 17=F4 18=F#4 19=G4 20=G#4 21=A4
# 22=A#4 23=B4（**上限**：线上 bitmap 只有 24 bit ⇒ 键号 ≤ 23）
