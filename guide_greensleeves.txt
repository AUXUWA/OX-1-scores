# Greensleeves（绿袖子） —— 单轨指引曲（OX-1 蓝牙曲谱文本文件）
# ------------------------------------------------------------
# 来源：英国/爱尔兰传统谣曲（PD，约 16 世纪）
# 调性：A 小调
# 板载音色：**preset 5 Supersaw**（板载 8 套之一，按板号 0~7）
# 建议 step_ms：**120**（四分音符 = 4 步 = 480 ms ⇒ ≈ 125.0 BPM）
# 规模：19 音 / 谱长 96 步 / 约 11.5 s
# 音域：7 (G3) .. 17 (F4)　★ 全部 ≤ 23 ⇒ 越界音 = 0
# ------------------------------------------------------------
# 格式：`step key [dur]` —— tools/score_push.py 的 read_score_file 与
#       tools/check_score_files.py 共用同一份解析器。
# ★ 键号口径：**0 = C3，12 = C4，23 = B4**（线上 bitmap 24 bit ⇒ 24=C5 发不出去）。
# ★ 谱长口径：**total_steps = max(step+dur)**（不是事件个数）。
# ★ 休止用"不写事件"表示 ⇒ 那一段灯是灭的，跟弹者知道该等。
# 原谱起音 A4、最高 F5（F5=29 > 23）⇒ **整体降一个八度**；和声小调 ⇒ 与 Supersaw 的电子音色最搭。
