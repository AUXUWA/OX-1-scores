# 来源：scores/china_4x32.json（同一份数据的**文本视图**）

#        py tools/score_to_bin.py --file scores/china_4x32.txt --loop 1

# ★ 这是 **4 轨合并谱**：同一时刻所有轨的键位 OR 进一个 bitmap
#   （与 scores/demo_camfg_4x32.txt 同款）。
# ★ 每步的 dur = 该步所有轨里**最长**的那条门（便于 .txt 单独下发时不丢延音）。
# ★ 步长 150 ms；共 32 步 = 4.80 s / 轮。
#
# ── 轨与音色（板级音色库 patch_bank.v 的 8 套）────────────────
#  轨0 笛      音色 羽管键琴       patch=0 algo=0 FB=0  声部 124 part 0  主旋律（五声，长音 + 装饰）
#  轨1 古筝     音色 弦乐群        patch=6 algo=6 FB=5  声部 125 part 1  古筝式分解（宫-商-角-徵）
#  轨2 低音     音色 管风琴        patch=4 algo=4 FB=0  声部 126 part 2  低音（宫-徵-羽-商）
#  轨3 磬      音色 钟          patch=7 algo=7 FB=0  声部 127 part 3  点缀（一记一记，不成拍）
#
# ── 键号表（半音偏移，0=C3）────────────────────────────────
